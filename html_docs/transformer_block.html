03. Transformer Block: Internals & Normalization

Why should I care?

A single transformer block contains multiple components: Layer Normalization, Self-Attention, Feed-Forward Networks, and Residual Connections. If you do not understand how these layers interact, you cannot debug training instability (like vanishing or exploding gradients). Properly configuring normalization locations (Pre-LN vs. Post-LN) and initialization scaling is the difference between a model that converges stably and one that returns NaNs.

Level 1 — Intuition & Mental Model

Imagine a pipeline where a signal is processed by a sequence of processing stations. If each station simply transforms the signal, any errors or distortion introduced early on will be amplified at each step, eventually ruining the signal.

To prevent this, we introduce two key designs:

  • Residual Connections: Instead of passing the transformed signal directly to the next station, we add the transformation back to the original input signal ($x + f(x)$). This preserves a clean copy of the original signal throughout the pipeline.
  • Layer Normalization: Before a station processes the signal, we normalize its values to prevent them from growing too large or too small. This keeps the signal magnitude stable at every step.

Level 2 — Engineering View

In model.py:L144-L170, the Block class defines a single transformer block: 

class Block(nn.Module):
    def __init__(self, config: GPTConfig) -> None:
        super().__init__()
        self.ln_1 = nn.LayerNorm(config.n_embd)
        self.attn = CausalSelfAttention(config)
        self.ln_2 = nn.LayerNorm(config.n_embd)
        self.mlp = MLP(config)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        x = x + self.attn(self.ln_1(x))
        x = x + self.mlp(self.ln_2(x))
        return x
This structure implements **Pre-LN**, applying LayerNorm to the hidden states before passing them to the Attention and MLP blocks.

3. Mathematical View & Gradient Flow

In the Pre-LN layout: $$x^{(l)} = x^{(l-1)} + F_l(\text{LayerNorm}(x^{(l-1)}))$$ Applying the chain rule, the gradient of the loss $\mathcal{L}$ with respect to the input $x^{(0)}$ is: $$\frac{\partial \mathcal{L}}{\partial x^{(0)}} = \frac{\partial \mathcal{L}}{\partial x^{(L)}} \left( I + \sum_{l=1}^L \frac{\partial F_l(\text{LayerNorm}(x^{(l-1)}))}{\partial x^{(0)}} \right)$$ Because of the identity matrix term $I$, gradients can propagate directly from the final layer back to the input, preventing the vanishing gradient problem.

4. Build Intuition through Numbers: LayerNorm Walkthrough

Let's calculate Layer Normalization manually for a single token embedding vector $X = [4.0, 2.0]$ (dimension $C=2$). Assume the learnable parameters are initialized to their defaults: scale $\gamma = [1.0, 1.0]$ and shift $\beta = [0.0, 0.0]$, and $\epsilon = 1e-5$.

Step 1: Compute Mean ($\mu$)

$$\mu = \frac{4.0 + 2.0}{2} = 3.0$$

Step 2: Compute Variance ($\sigma^2$)

$$\sigma^2 = \frac{(4.0 - 3.0)^2 + (2.0 - 3.0)^2}{2} = \frac{1.0 + 1.0}{2} = 1.0$$

Step 3: Normalize

$$\hat{X}_1 = \frac{4.0 - 3.0}{\sqrt{1.0 + 1e-5}} \approx 1.0$$ $$\hat{X}_2 = \frac{2.0 - 3.0}{\sqrt{1.0 + 1e-5}} \approx -1.0$$

Step 4: Scale and Shift

$$Y = \gamma \odot \hat{X} + \beta = [1.0, 1.0] \odot [1.0, -1.0] + [0.0, 0.0] = [1.0, -1.0]$$ The input vector $[4.0, 2.0]$ has been normalized to $[1.0, -1.0]$, keeping the activation magnitudes stable.

5. What happens if we remove LayerNorm?

If we remove all LayerNorm layers, training will fail to converge. Without normalization, activation magnitudes grow exponentially as they pass through the layers and blocks. When they reach the final classification layer, the logits will be extremely large, pushing the softmax function to return gradients near 0. This is the **vanishing gradient problem**, which halts weight updates and stops learning.
