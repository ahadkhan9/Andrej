04. MLP & LayerNorm: Processing Pipelines

00. Overview → 01. BPE Parsing → 02. Embeddings → 03. Attention → 04. Pipelines → 05. Generation

The Token's Journey

Having gathered context from surrounding tokens during attention, our token vector $x$ must now be standardized, individual features mapped, and values integrated back into the residual highway.

  1. Pre-Layer Normalization: Before entering attention or the feed-forward network, "The Token's" hidden activations are normalized to mean 0 and variance 1 to maintain mathematical stability.
  2. Residual Skip (Attention): The output from attention is added back to "The Token's" original incoming state: 
    x = x + attention(ln_1(x))
  3. Multi-Layer Perceptron (MLP): Standardized vector features are projected up to 4x width (from $C=384$ to $4C=1536$), filtered through a GELU activation function, and projected back down to $C=384$.
  4. Residual Skip (MLP): The final processed state is added back to the residual stream: 
    x = x + mlp(ln_2(x))
flowchart TD Input["Incoming Vector: x"] -->|Pre-LN 1| LN1["LayerNorm [B, T, C]"] LN1 -->|Attention Block| Attn["Attention Output [B, T, C]"] Input & Attn -->|Residual Add| Add1["Summed Stream: x + Attn"] Add1 -->|Pre-LN 2| LN2["LayerNorm [B, T, C]"] LN2 -->|Linear c_fc| UpProj["Expanded Features: [B, T, 4C]"] UpProj -->|GELU Activation| Act["Non-Linear Filtering"] Act -->|Linear c_proj| DownProj["MLP Output: [B, T, C]"] Add1 & DownProj -->|Residual Add| Output["Final Block Output: x + MLP"]

Backend Engineer Lens: Middleware Chains

In software architecture, the Transformer Block structure mirrors a **middleware request-response preservation chain**.

  • LayerNorm → Input Standardization: Think of this as parameter formatting middleware. It standardizes inputs so that data anomalies don't cause processing exceptions (underflow/overflow) down the line.
  • Residual Streams → Request Context Bypass: Think of the residual connection as passing the original HTTP Request Context object down the handler chain. Each handler (Attention or MLP) returns a payload difference that is added to the context. Even if a handler fails or collapses values to zero, the original request payload is still safely preserved and bypassed down the stream.
  • MLP Block → Worker Thread Handlers: Attention lets tokens talk to each other (cross-node communications). Once context is gathered, the MLP acts like independent CPU worker threads executing business logic on each token record individually, without communicating with other threads.

Production Relevance

  • Pre-LN Stability: Original transformers (Post-LN) normalized activations *after* residual additions. This caused gradients near output layers to be massive while vanishing near input layers, requiring delicate learning rate schedules. Pre-LN (used in GPT-2 and modern Llama models) normalizes inputs *before* each block, allowing gradients to propagate directly through the clean residual highway during backpropagation, stabilizing large-scale training.
  • RMSNorm Upgrade: In production models (e.g. Gemma, Llama), standard LayerNorm (which calculates mean and variance) is replaced by Root Mean Square Normalization (RMSNorm). RMSNorm omits calculating the mean, scaling activations based solely on their root mean square. This reduces math calculations, speeding up GPU runtime by 10-50%.

Verification

We verify the stability of this pipeline by running the overfitting check: without Pre-LN and residual scales, training gradients explode immediately. With them, training loss decreases monotonically from $10.8$ to under $0.01$ in under 120 steps on a single batch:

python3 train.py --overfit

Common Interview Followups

Why do residual skip connections solve the vanishing gradient problem?

In backpropagation, we calculate the derivative of a block output with respect to its input. Given a residual block $y = x + F(x)$, the derivative of $y$ with respect to $x$ is: $$\frac{\partial y}{\partial x} = 1 + \frac{\partial F(x)}{\partial x}$$ When computing backpropagation, the gradient is multiplied by this term. Even if the sub-layer weights degrade and the local gradient $\frac{\partial F(x)}{\partial x}$ vanishes to zero, the "$1 +$" term ensures that the gradient can flow back completely unimpeded along the entire network depth, directly back to the initial embeddings.

Why does GPT-2 scale weights at residual projections by $1/\sqrt{2 \cdot \text{n\_layer}}$ during initialization?

Every time we pass through a transformer block, we add a residual block output to the main vector stream: $x_{next} = x + F(x)$. Adding these independent random variables increases the variance of the activation signals. If the variance grows too large, activations blow up near output layers, destabilizing training. To prevent this, we scale the weight initialization of all residual projection layers (`c_proj` in attention and MLP) by a factor of $\frac{1}{\sqrt{2 \cdot N}}$ (where $N$ is the number of layers), ensuring activation variance remains stable at 1.0 throughout the entire network depth.
