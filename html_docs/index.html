00. Welcome & Course Overview

Why should I care?

Most software engineers treat Large Language Models (LLMs) as black boxes, calling APIs (like OpenAI or Anthropic) or loading pre-trained models via library imports. But the moment you need to optimize inference latency, write custom fine-tuning code, reduce KV Cache memory usage, debug a model returning NaN, or discuss core scaling architectures during a staff-level systems interview, black-box knowledge fails. Understanding transformers from first principles—down to the exact PyTorch tensors, gradient updates, and memory allocations—is the dividing line between an application developer and a senior AI/ML systems engineer.

Level 1 — Intuition & Mental Model

Imagine a team of 6 researchers (the Transformer Blocks) sitting in a line. A document is passed down the line, page by page. Before the document enters the room, we translate all words into a standardized numeric format (Tokenization) and assign each word a baseline folder containing its raw definition and its page number (Embeddings).

As the document passes through the researchers:

  • Each researcher runs a "Self-Attention" pass: they look at all pages received so far, drawing red marker lines between words that relate to each other (e.g., connecting "he" back to "Alan Turing").
  • Then, they run an "MLP" pass: each researcher works individually on their assigned page, using their own reference manual to look up facts, cross-reference data, and rewrite the summary details.
  • Finally, the document reaches the supervisor (the LM Head), who looks at the final summary of the final word and makes a prediction on what word should come next.

Level 3 — Mathematical View

The core training objective is to find parameter weights $\theta$ that minimize the cross-entropy loss over a sequence of tokens. Given a sequence of input tokens $x = (x_1, x_2, \dots, x_T)$, the model computes conditional probabilities for each position $t$: $$P(x_t \mid x_{1}, \dots, x_{t-1}) = \text{Softmax}(\text{lm\_head}(h_t^{(L)}))$$ Where $h_t^{(L)}$ is the final representation of token $t$ after passing through all $L$ transformer blocks. The loss function (negative log-likelihood) is computed over the entire sequence: $$\mathcal{L} = -\frac{1}{T} \sum_{t=1}^T \ln P(x_t \mid x_{1}, \dots, x_{t-1})$$ By calculating the derivative of this loss with respect to all parameter weights ($\nabla_\theta \mathcal{L}$), the optimizer (AdamW) updates the model parameters to make correct word predictions more likely.
