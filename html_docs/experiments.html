14. Experiment Lab: Structural Modifications

The Token's Journey

By conducting systematic ablation studies (removing or altering specific model structures), we observe exactly how each component affects the token's information flow and training convergence.

Backend Engineer Lens: Infrastructure A/B Testing

Systematic ablation studies mirror **A/B testing database indexing structures and disabling middleware components** to isolate performance bottlenecks.

  • Removing Residual Skip Connections → Disabling request context bypass: If we delete residual additions, the gradient feedback trace cannot bypass layers. Optimization fails because the feedback never reaches the initial layers.
  • Removing Position Embeddings → Dropping database sort order indexes: Removing positional embeddings is identical to stripping a database query of ORDER BY indexes. The database treats records as a bag-of-words. The model loses all grammatical and semantic order awareness.
  • Swapping GELU for ReLU → Downgrading validation logic: ReLU acts like a strict validator that throws an exception for negative values (zeroes out negative parameters). Swapping to GELU (Gaussian Error Linear Unit) allows a smooth, non-zero gradient for negative values, preventing "dead neuron" bottlenecks.

How to Conduct Experiments

To run these ablation tests on your machine:

  1. Apply the respective code modification outlined in the table above inside `model.py`.
  2. Launch training for 60 steps using FP16 mixed precision: 
    python3 train.py --steps 60 --amp
  3. Observe validation loss values output to the console and compare against healthy baseline parameters.

Common Interview Followups

Why do we use GELU instead of ReLU in modern transformer networks?

ReLU is defined as: $$\text{ReLU}(x) = \max(0, x)$$ If a neuron receives a negative input, its output is zero, and its gradient is also zero. If weights update such that a neuron always receives negative inputs, its weights will never update again, rendering it permanently inactive ("dead neuron"). **GELU** (Gaussian Error Linear Unit) scales inputs smoothly: $$\text{GELU}(x) = x \cdot \Phi(x)$$ Where $\Phi(x)$ is the cumulative distribution function of the standard normal distribution. Because it is non-zero for negative inputs, it allows a small gradient to propagate, preventing dead neurons and stabilizing training.

What occurs if you remove position embeddings from a transformer model?

If you remove position embeddings, the model becomes completely order-blind. Because the self-attention formula computes dot-products between all token pairs, the output for "dog bites man" and "man bites dog" will be identical. The model treats the input as a "bag of words" and loses all awareness of syntax, grammar, and word ordering, resulting in high validation losses and ungrammatical generated sentences.
