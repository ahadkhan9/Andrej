05. Data Pipeline: Batch Construction & Offsets

Why should I care?

A machine learning model is only as good as the data fed into it. Because language modeling is self-supervised (predicting the next token based on previous tokens), we must structure our data loaders to align input sequences and target sequences correctly. If your data loader contains a coordinate alignment bug or a target leakage error, the model will learn incorrect sequence patterns or simply fail to train.

Level 1 — Intuition & Mental Model

Imagine you are teaching a child to read by showing them a sentence, one word at a time. If the sentence is "The quick brown fox jumps":

  • When you show the child "The", their target is to guess "quick".
  • When you show them "The quick", the target is "brown".
  • When you show them "The quick brown", the target is "fox".
To train the model, we need to construct pairs of input sequences ($X$) and target sequences ($Y$) shifted by exactly one position. This means for every batch we load, we must fetch $N$ tokens for the input sequence, and the same tokens shifted by one position for the targets.

Level 2 — Engineering View

In data.py, the DataLoaderLite class implements this sliding window approach. To construct a batch of size $B$ (batch size) and $T$ (sequence length), we slice $B \times T + 1$ contiguous tokens from the raw data buffer: 

# From data.py:L47-L51
buf = self.tokens[self.current_position : self.current_position + B * T + 1]
x = buf[:-1].view(B, T)
y = buf[1:].view(B, T)
We advance self.current_position by $B \times T$ at each step. If the next step would overflow the dataset boundaries, we wrap the position back to 0:

# From data.py:L57-L58
if self.current_position + B * T + 1 > len(self.tokens):
    self.current_position = 0

3. Mathematical View

Let $S$ be the sequence of tokens loaded from the dataset: $$S = [s_0, s_1, s_2, \dots, s_{B \cdot T}]$$ The input tensor $X \in \mathbb{R}^{B \times T}$ and target tensor $Y \in \mathbb{R}^{B \times T}$ are constructed as: $$X_{i, j} = S_{i \cdot T + j}$$ $$Y_{i, j} = S_{i \cdot T + j + 1}$$ Where $0 \leq i < B$ represents the batch index, and $0 \leq j < T$ represents the sequence index.

4. Build Intuition through Numbers

Let's walk through batch construction manually for a batch size $B=2$ and context length $T=3$ (requiring $2 \times 3 + 1 = 7$ contiguous tokens). Assume our raw dataset contains the tokens: $$S = [45, 12, 98, 30, 87, 54, 21]$$

Step 1: Slice the Buffer

$$\text{buf} = [45, 12, 98, 30, 87, 54, 21]$$

Step 2: Construct Input Tensor ($X$) (take all but the last token, and reshape to $2 \times 3$):

$$X_{flat} = [45, 12, 98, 30, 87, 54]$$ $$X = \begin{pmatrix} 45 & 12 & 98 \\ 30 & 87 & 54 \end{pmatrix}$$

Step 3: Construct Target Tensor ($Y$) (take all but the first token, and reshape to $2 \times 3$):

$$Y_{flat} = [12, 98, 30, 87, 54, 21]$$ $$Y = \begin{pmatrix} 12 & 98 & 30 \\ 87 & 54 & 21 \end{pmatrix}$$ Comparing $X$ and $Y$ row-by-row, you can see that the target for each token is the next token in the sequence (e.g., the target for token 45 is 12, and the target for token 30 is 87).

5. What happens if we remove the shifted target offset?

If we fail to shift the target tokens by one position (i.e. setting $Y = X$):

  • The model's training objective changes from predicting the *next* token to predicting the *current* token (identity mapping).
  • The model will easily achieve a near-zero loss by simply copying each input token to its output, without learning any semantic relationships or sequence structures.
  • During inference generation, the model will generate repetitive strings of the prompt token (e.g., generating "Alan Alan Alan" for the prompt "Alan") because it has only learned to predict the input token itself.
