18. GenAI Developer Study Roadmap

Why should I care?

Building a local GPT model is the first step on the journey of an LLM Systems Engineer. To transition from toy implementations to production architectures, you need a structured study roadmap. This curriculum maps out your next steps, connecting base model theory to fine-tuning, high-throughput serving, context indexing, and agent orchestration.

Common Interview Followups

What is the difference between Supervised Fine-Tuning (SFT) and Reinforcement Learning from Human Feedback (RLHF)?

  • Supervised Fine-Tuning (SFT): Trains the model on direct instruction-response pairs (e.g. User: "Hello", Assistant: "Hi"). The model is trained using cross-entropy loss to match target text patterns. This teaches the model the **structure and style** of assistant behavior.
  • Reinforcement Learning from Human Feedback (RLHF): Aligns the model's behavior with human preferences (safety, helpfulness). We train a secondary "Reward Model" to score LLM responses. We then optimize the target LLM using policy gradient algorithms (like PPO or DPO) to maximize reward scores. This aligns **tone, safety, and policy compliance** beyond simple pattern matching.

How does Tool Calling work under the hood in Agent systems? Does the LLM execute the function?

No, the LLM never executes the tool code itself. The tool execution loop is handled by your backend application:

  1. You provide the LLM a text description of your functions (e.g. a JSON schema for fetch_user(user_id)).
  2. The LLM decides a function call is needed and outputs a structured text string (e.g. JSON: {"tool": "fetch_user", "args": {"user_id": 12}}) instead of a natural response.
  3. Your backend application reads this output, parses the JSON payload, runs the actual Python/C# function locally, and retrieves the results.
  4. The application formats the function results as a text string, appends it back to the LLM's context, and queries the LLM again to synthesize the final answer.
