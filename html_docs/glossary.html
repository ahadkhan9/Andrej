19. Glossary of Terms & Index

Why should I care?

This reference index provides concise, systems-level definitions of core Large Language Model (LLM) and transformer terminology, mapping each concept to its backend parallel and codebase location.

Terminology Directory

Term Systems Definition Backend Engineer Lens Code Pointer
KV Cache Caching Key and Value tensors of past sequence tokens during autoregressive inference to prevent $O(T^2)$ recomputations. Caching read indexes of static database assets to reduce request processing time to $O(1)$. N/A (KV Cache scale details are in Chapter 15)
Weight Tying Sharing parameters between the input token embedding layer (`wte`) and the output language modeling head (`lm_head`). Sharing database schema memory configurations across multiple services to minimize local storage requirements. model.py: wte weight tie
Residual Stream The skip connection pathway that adds block inputs directly to block outputs, allowing gradients to bypass layers during backprop. Request Context bypass middleware, safeguarding original request state from downstream mutations. model.py: Block.forward()
LayerNorm Standardizing hidden activation distributions to mean 0 and variance 1 across the final dimension to prevent optimization collapse. Input data formatting and validation middleware, guarding against numeric database anomalies. model.py: ln_1, ln_2
Perplexity Exponentiated cross-entropy loss, measuring a model's uncertainty when predicting the next token. System anomaly rate or latencies metrics mapping confidence. Calculated from evaluation loss in Chapter 10
Causal Masking An upper-triangular negative-infinity bias matrix applied to attention scores to prevent tokens from looking ahead at future targets. SQL isolation levels, enforcing `Read Uncommitted` boundaries to prevent database leaks. model.py: register_buffer
FLOPs Floating-Point Operations, measuring the computational complexity of running model training or inference. CPU/GPU cycle budgets or server resource constraints. Traced during speed checks in Chapter 08
Mixed Precision (AMP) Executing matrix multiplications in lower-precision formats (FP16 or BF16) while keeping master copies in FP32 format. Data type compression, reducing field sizes from 64-bit to 32-bit/16-bit to double cache throughput. train.py: autocast blocks
BPE Merges Merges common subword sequences iteratively based on pair frequency, building the tokenizer vocabulary. Token dictionary compilation, defining catalog primary keys. data.py: tiktoken load
Triton Kernels GPU execution modules written in OpenAI's Triton language, bypassing standard PyTorch dispatcher limitations. Writing inline C++ assemblies or assembly-level drivers for database lookups instead of utilizing an ORM. Used in production equivalent serving systems (vLLM)
