14. Glossary of Terms

A quick-reference index of core terminology, metrics, and optimization concepts used in Large Language Model engineering.

Term Definition
Activation Intermediate tensor outputs computed during the forward pass of a model (e.g. outputs of linear layers, attention weights) that must be saved in memory to compute gradients during backpropagation.
AdamW An optimizer that combines adaptive learning rates with decoupled weight decay (L2 regularization), updating model weights based on historical gradient moments.
BF16 (Bfloat16) Brain Floating Point (16-bit). A numerical format that has the same dynamic range as float32 but lower precision, offering better numerical stability than standard float16 without requiring loss scaling.
Causal Masking A mechanism in decoder-only models that prevents tokens from attending to future positions, implemented by adding an upper-triangular matrix of $-\infty$ to the attention logits.
FlashAttention An optimized attention algorithm that tiles computation into SRAM cache blocks, reducing HBM memory access from $O(T^2)$ to $O(T)$ to speed up execution.
FLOPs Floating Point Operations. A metric used to measure computational workload. The forward and backward passes of a transformer require roughly $6N$ FLOPs per token (where $N$ is parameter count).
GQA Grouped Query Attention. An attention mechanism where multiple Query heads share a single Key-Value head, reducing the KV cache size to speed up inference.
Gradient Accumulation A training technique that sums gradients over multiple micro-batches before taking an optimizer step, simulating a large batch size on hardware with limited memory.
KV Cache Storing Key ($K$) and Value ($V$) projections of past tokens in memory during generation, avoiding redundant calculations for new token predictions.
LayerNorm Layer Normalization. Normalizes activations across the embedding dimension for each token, improving training stability.
Perplexity An evaluation metric defined as $e^{\mathcal{L}}$ (where $\mathcal{L}$ is cross-entropy loss). It represents the effective branching factor of the model's predictions.
Pre-LN Applying Layer Normalization to inputs before passing them to the attention or MLP blocks, maintaining a clean gradient path through residual connections.
RMSNorm Root Mean Square Normalization. A simplified version of LayerNorm that normalizes activations using only the root mean square value, reducing computational overhead by omitting mean calculations.
RoPE Rotary Position Embedding. Projects Query and Key vectors into the complex plane to inject relative positional information, enabling context length scaling.
SwiGLU A gated feed-forward activation function that combines the Swish activation with a Gated Linear Unit, improving convergence rates in modern LLMs.
Weight Tying Sharing parameters between the input token embedding matrix (wte) and the final projection head (lm_head) to reduce model memory footprint.
