12. Connections to Modern LLMs

Why should I care?

The transformer architecture has evolved significantly since GPT-2 was introduced in 2019. Modern models (such as Llama, Gemma, and Mistral) incorporate optimizations designed to scale context lengths, reduce inference latency, and speed up training. Understanding these evolutionary steps is essential for designing custom training runs, optimizing model deployment, and working with modern LLM systems.

Level 1 — Intuition & Mental Model

Think of GPT-2 as an early internal combustion engine. It established the core principles of operation, but was inefficient and lacked refinements. Modern models are like modern hybrid engines:

  • RoPE: Replaces absolute position markings with a relative system, allowing the model to generalize to much longer context windows.
  • RMSNorm: Simplifies LayerNorm by assuming the mean of activations is 0, reducing computational overhead.
  • Grouped Query Attention (GQA): Divides Query heads into groups that share Key-Value heads, significantly reducing KV cache memory usage during inference.
  • SwiGLU: Introduces a gating mechanism to the MLP block, allowing the model to learn complex coordinate-wise multiplicative interactions.

Level 2 — Engineering View: Comparative Evolution

The following table tracks how these core components evolved from GPT-2 to modern architectures:

Component GPT-2 Design Modern Design (Llama-3, Gemma-2, Qwen-2.5) Why it changed
Position Representation Absolute Positional Embeddings (learnable matrix of size $T \times C$) Rotary Position Embeddings (RoPE) Enables context length scaling (e.g. from 1k to 128k+ tokens) during inference.
Normalization LayerNorm (calculates both mean and variance) RMSNorm (calculates root mean square only) Reduces computational overhead by 10-50% for normalization layers, improving training speed.
Attention Multi-Head Attention (MHA) Grouped Query Attention (GQA) Reduces the KV cache memory footprint by 8x, allowing larger batch sizes during inference.
MLP block Standard FFN with GELU activation SwiGLU FFN Introduces a gating mechanism that improves model convergence rates.
Model Architecture Dense model Mixture of Experts (MoE) (in DeepSeek, Mixtral, GPT-4) Allows scaling the total parameter count while keeping the active parameter count per token small.

3. Mathematical View: RoPE and RMSNorm

RMSNorm:

RMSNorm simplifies LayerNorm by omitting the mean calculation, normalizing activations using only the root mean square value: $$\text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d} \sum_{i=1}^d x_i^2 + \epsilon}} \odot \gamma$$

Rotary Position Embeddings (RoPE):

RoPE represents Query and Key vectors in the complex plane, applying a rotation matrix based on token position $m$: $$R_{\Theta, m}^d = \text{diag}\left( R_{\theta_1, m}, R_{\theta_2, m}, \dots, R_{\theta_{d/2}, m} \right)$$ Where $R_{\theta_i, m}$ is a 2D rotation matrix: $$R_{\theta_i, m} = \begin{pmatrix} \cos(m\theta_i) & -\sin(m\theta_i) \\ \sin(m\theta_i) & \cos(m\theta_i) \end{pmatrix}$$ By applying this rotation to $Q$ and $K$, the attention dot product becomes dependent only on the relative distance between tokens ($m - n$), allowing the model to generalize to longer context windows.
